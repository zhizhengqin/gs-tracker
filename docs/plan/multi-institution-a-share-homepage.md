# 工程计划：多机构 A 股情报首页

Generated by /plan-eng-review on 2026-08-04
Status: READY
Branch: main

## 摘要

GS-Tracker 当前只覆盖高盛一家机构。本次升级在现有架构上渐进式添加多机构支持——给信号打机构标签，新增 QFII 和北向资金两个 A 股数据源，首页改为"多机构汇总视图"。不改管道核心逻辑，不重建数据库 PK，5 组改动包，预计 8 个文件。

## 前提

1. A 股优先：QFII 季度持仓 + 沪深港通日频为新增核心数据源，美股 13F 保留为辅
2. 首页是"所有机构汇总视图"（带机构标签），单机构详情页留给 Phase 2
3. 不改现有管道核心流程（`run_pipeline_stream`、`run_daily_intel_stream` 不动）
4. 数据库迁移用 `ALTER TABLE ADD COLUMN` + 唯一索引，不重建 PK

## 实施变更

### A 组：Signal 加机构标签（3 文件）

- `signals/base.py` — Signal 加 `institution_id: str = "gs"` 字段
- `storage.py` — signals 表 `ALTER TABLE ADD COLUMN institution_id TEXT DEFAULT 'gs'`；加唯一索引 `(quarter, institution_id, id)`；`get_recent_signals(days, institution_id=None)` 和 `get_signals_by_date(date, institution_id=None)` 加可选过滤参数
- `signals/aggregator.py` — 聚合时给所有信号打 `self.institution_id`

### B 组：News 源支持 JPM 关键词（1 文件）

- `signals/news_source.py` — 加 `JPM_KEYWORDS` 和 `JPM_VIEWPOINT_KEYWORDS` 常量；`NewsSource.__init__` 加 `institution_id` 参数；`_match_gs()` 和 `_has_viewpoint()` 按 `institution_id` 动态选择关键词组

### C 组：A 股新数据源（2 新文件）

- `signals/qfii_source.py` — QFII 季度持仓披露源。从东方财富 QFII 数据中心抓取（`https://data.eastmoney.com/qfii/`），解析 HTML 表格，生成 `Signal(source="qfii", institution_id="gs"|"jpm")`，每季度拉取一次
- `signals/northbound_source.py` — 沪深港通北向资金日频源。从东方财富/同花顺公开接口获取日频汇总数据（净买入额、成交额、持仓市值），生成 `Signal(source="northbound")`，不绑定单家机构（`institution_id` 留空或 `"all"`）

### D 组：日报 + API（2 文件）

- `daily_report.py` — `generate_daily_report(date, institution_id=None)` 加可选参数；机构参数为 None 时生成"多机构汇总日报"，AI 提示词从"高盛情报分析师"改为"机构情报分析师"，要求对比 GS/JPM 观点异同
- `web.py` — 日报 API 加 `?institution=` 参数；新增 `GET /api/institutions` 返回机构列表；信号 API 加 `?institution=` 过滤

### E 组：首页 UI 改版（1 文件）

- `templates/dashboard.html` — 首页"每日情报"区域改为汇总视图：信号卡加机构标签（GS 蓝色 / JPM 绿色）；左侧栏加机构筛选（全选 / GS / JPM）；默认显示所有机构的信号

## 不改的范围

- 季度对账管道（`run_pipeline_stream`）不改
- 季度报告 HTML 生成不改
- 通知推送不改
- 用户认证不改
- 调度器不改

## 假设与默认选择

- QFII 数据源使用东方财富公开页面，httpx 可直接抓取（无 JS 渲染）
- 北向资金使用东方财富 JSONP 接口，日频更新
- 机构标签颜色：GS 蓝色 `#1a56db`，JPM 绿色 `#047857`，未来扩展预留 6 色位
- Signal 去重 key 保持 `(source, title)`，不加 institution——因为不同机构的同标题信号本身就是不同的信息（GS 说买 vs JPM 说卖）
- 本次不引入新第三方依赖
